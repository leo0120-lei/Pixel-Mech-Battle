# Pixel-Mech-Battle
# 🤖 机甲对战 - Pixel Mech Battle

一款基于 Node.js + WebSocket 的实时双人对战游戏，支持**本地双人**和**网络联机**模式。玩家可选择不同武器，通过格斗、投掷、射击击败对手，采用回合制比分（先得5分者胜）。

## 🎮 游戏特色

- **像素机甲风格**：Canvas 渲染，流畅动画与打击特效
- **双模式**：本地双人（同一设备） / 联机对战（跨设备）
- **武器系统**：6 种武器可选（拳头、激光剑、长矛、手里剑、爆能枪、火箭筒），各有独特的伤害、攻速、攻击范围和特殊能力（投掷/射击）
- **账户系统**：注册 / 登录，支持修改用户名和密码（密码明文存储仅用于演示）
- **回合制比赛**：每局独立，率先赢得 5 回合者获胜
- **实时同步**：WebSocket 保证联机低延迟同步

## 🕹️ 操作说明

| 操作         | 玩家1 (左)          | 玩家2 (右)         |
|--------------|---------------------|--------------------|
| 移动左右     | A / D               | ← / →             |
| 跳跃         | W                   | ↑                 |
| 攻击         | 空格                | ↓                 |
| 投掷武器*    | S                   | Ctrl              |

*仅限可投掷武器（手里剑、爆能枪、火箭筒）*
